# Peaceful Framework

Small Roblox service/controller framework. Signal, Trove, Net, Scheduler, Component, Store included.

## Structure

```
src/ReplicatedStorage/PeacefulFramework/  - core modules + usage examples (README.lua)
src/ServerScriptService/                  - server bootstrap
src/StarterPlayer/StarterPlayerScripts/   - client bootstrap
```

## Setup

Use [Rojo](https://rojo.space) with `default.project.json`, or copy the repo contents into the fitting services yourself.
 
## Usage

you can see `src/ReplicatedStorage/PeacefulFramework/README.lua` for examples of every module's usages
